STOCKPILOT 2.0 for Linux (x64) - a mod for Screen Stocks

Install:   open a terminal in this folder and run   ./install.sh
           StockPilot then shows up in your app menu. No root needed.
           (Ubuntu / Debian / Mint users can use the .deb instead - just double-click it.)
Uninstall: ./uninstall.sh

Screen Stocks runs through Steam Proton on Linux - StockPilot finds the game files there by itself.
The game must be open for trades to happen.
