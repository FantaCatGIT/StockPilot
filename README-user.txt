STOCKPILOT v2.0 - a mod for Screen Stocks
Live charts, one-click trading, portfolio, dividends, journal, statistics, news,
auto actions, an experimental bot and custom skins (picture / GIF / MP4).
Light theme by default - Dark is in Settings. Uses the game's official mod support.

WINDOWS 10 / 11 - one file for every Windows PC - it installs the right version for your PC
  (64-bit Intel/AMD, 32-bit, or ARM / Snapdragon)
  Windows\StockPilot Setup 2.0.0.exe -> run it.
  If Windows says "Windows protected your PC": More info > Run anyway.
  If StockPilot ever can't start, it now shows why and saves it to %APPDATA%\StockPilot\error.log
  StockPilot then appears in the Start menu and on the desktop. Uninstall: Settings > Apps.

macOS (Apple Silicon: M1 / M2 / M3 / M4)
  macOS\StockPilot-2.0.0-macOS.dmg -> open it, right-click "Install StockPilot.command" > Open.
  (macOS 15+: if it can't be verified, System Settings > Privacy & Security > Open Anyway.)

LINUX (x64, any distro incl. Steam Deck)
  Linux\StockPilot-2.0.0-linux-x64.tar.xz -> unpack it, open a terminal in the folder, run ./install.sh
  StockPilot then shows up in your app menu (no root needed). Uninstall: ./uninstall.sh

Upgrading from StockPilot 1.x? Just install 2.0 - the old version is stopped and removed,
and your chart history, auto actions and settings come over on the first start.
The game must be open for trades to happen.
