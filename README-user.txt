STOCKPILOT v1.1 - a mod for Screen Stocks
Auto rules bot, live charts, daily profit and a calculator.
Uses the game's official mod support.

Windows -> Windows/StockPilot-Setup.exe
Mac     -> macOS/StockPilot.dmg
Linux   -> Linux/StockPilot-x86_64.AppImage

Upgrading from "Screen Stocks Panel"? Just install StockPilot - your rules and
chart data move over and the old version is removed.
The game must be open for trades to happen.
